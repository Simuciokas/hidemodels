**Adds builds for Minecraft 26.1.1 and 26.1.2.** 1.4.0 shipped a jar for 26.1 but not for its two
patch releases, so anyone on 26.1.1 or 26.1.2 had no jar naming their version. There are now
fourteen, one for every Minecraft release from 1.21.2 onward.

The mod itself is unchanged from 1.4.0 — same behaviour, same config file, same command. If you are
already running 1.4.0 on a version that was covered, there is nothing here for you.

### Which jar do I want

The one whose name matches your Minecraft version exactly — `hidemodels-1.4.1+mc26.1.2.jar` for
26.1.2. Each jar declares the version it was built for, so Loader refuses the wrong one up front
rather than failing somewhere later.

Requirements are unchanged: Fabric Loader `>=0.19.0`, Java 25 on 26.x or 21 on 1.21.x, **no Fabric
API**, no other mods, and nothing server-side — it is client-only.

### The new versions were held to the same standard

Both were checked against their own client jars — every mixin target and every vanilla type the mod
names resolves — and both were launched in a real client, which confirmed the model component still
resolves from the registry and that editing the config still drives what gets hidden. That is the
same bar the other twelve versions clear on every push.
