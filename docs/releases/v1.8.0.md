**Minecraft 26.3, on all three loaders.**

### 26.3

26.3 landed on 15 September and this release covers it — Fabric, NeoForge and Quilt — bringing the
supported range to nineteen versions, 1.20.5 through 26.3.

Nothing changes for anyone on an earlier version: 26.3 shares a jar with 26.2, 26.1.2, 26.1.1 and
26.1, so the download you already use is the download you keep using. Still seven jars for nineteen
versions.

**Quilt needs nothing.** Quilt Loader runs the Fabric jar on 26.3 as it does on every other version.

**NeoForge on 26.3 is built against a NeoForge beta** (`26.3.0.1-beta`), because that is all
NeoForge has published for 26.3 so far. Every other NeoForge jar here is built against a stable
NeoForge release. If you would rather wait for one, use the 26.2 jar on 26.2 and hold off updating —
the Fabric and Quilt jars for 26.3 carry no such caveat.

### Why this was not a one-line change

26.3 replaced Minecraft's renderer, and the method this mod hooks to skip a model — `shouldRender` —
gained a parameter. A hook whose shape no longer matches its target does not degrade quietly; the
client refuses to start, which is the right failure and the reason it was caught before release
rather than after.

The mod now carries both shapes of that hook and uses whichever the running version declares, so one
jar still covers 26.1 through 26.3 with no split and no preprocessor.

### Tested, as usual, by running it

Every jar is built and launched on a clean machine before release. For 26.3 that took some doing:
its new render backend would not start on the CI runners at all — no matching GLX visual, no usable
Vulkan — so the test machines now carry a proper software graphics stack. 26.3 is launched and
driven in CI like every other version, not merely compiled.

The client gametest also gained a check that the render hook is actually installed, by calling
`shouldRender` and asserting a listed model comes back hidden. Until now every test covered the
matcher rather than the hook that acts on it — which is exactly the gap 26.3 walked into.
