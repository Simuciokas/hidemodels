**Hide a model without leaving the game, and four more Minecraft versions.**

### Click an id to hide it

`/hidemodels list` already told you the ids of the models around you. Now the ids that are not
hidden yet are underlined, and clicking one hides it immediately — no alt-tabbing to a config file,
no waiting for a reload. There are typed commands too:

* `/hidemodels add <id>` — hide it now
* `/hidemodels remove <id>` — stop hiding it

`add` appends to your config rather than rewriting it, so your comments and directives stay exactly
where you put them, and it tells you when an id is already covered by a broader line instead of
quietly adding a duplicate. `remove` takes out a line that matches exactly; if the id is only hidden
because of a broader pattern, it names that pattern rather than deleting more than you asked for.

Ids that are already hidden are deliberately **not** clickable. A click that appeared to do nothing
would be worse than no click, and removal stays a typed command so nothing vanishes from your config
because of a stray click in chat.

### Now 1.20.5 through 26.2

Four more versions — 1.21.1, 1.21, 1.20.6 and 1.20.5 — for eighteen in total, each with its own jar.

On 1.21.1 and older, Minecraft has no `item_model` component yet, so the mod keys on
`custom_model_data` instead. It works the same way; the ids you write in the config are those values
rather than model paths. 1.20.4 and earlier cannot be supported at all: data components do not exist
there, and they are what the mod identifies models by.

### Tested, as usual, by running it

Every one of the eighteen jars is launched in a real client in CI, and that check now covers the new
commands as well — including on 26.x, where Fabric ships no gametest harness at all. Where the full
gametest can run (1.21.4 through 1.21.8, five versions now rather than two) it drives `add` and
`remove` through the game's own command path, and on 1.21.6+ it also drives the separate path a
*clicked* command takes, printing which one it exercised so a skipped check cannot pass silently.
